# Mask-Hover

An interactive canvas-based image reveal effect using JavaScript and HTML5 Canvas. This project creates a dynamic hover mask where moving your mouse cursor acts like a flashlight or a magical brush, revealing a hidden image underneath the base image. The brush trail smoothly fades out over time, creating a visually pleasing interactive experience.

## Features
- **Canvas-based Rendering:** Uses HTML5 Canvas for high-performance image manipulation.
- **Dynamic Masking:** Follows the mouse cursor and uses a radial gradient for a smooth brush edge.
- **Fading Trails:** Brush trails smoothly fade out over time, giving a dynamic, temporal effect.
- **Responsive:** Automatically resizes and aligns both base and overlay images to cover the screen perfectly, regardless of window size.
